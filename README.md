# DesignHub — менеджер дизайн-проектов

Учебный проект по дисциплине **«Проектирование веб-сервисов»**. Создание и удаление проектов, изменение статуса, просмотр списка, расчёт стоимости заказа.

## Архитектура — четыре Docker-контейнера

| Сервис | Технологии | Назначение |
|---|---|---|
| frontend | HTML/CSS/JavaScript, Nginx | Интерфейс, кнопки и таблица |
| backend | Python, FastAPI, Psycopg | REST API, операции с PostgreSQL |
| db | PostgreSQL 16 | Хранение проектов |
| web-service | Python, FastAPI | Отдельный калькулятор цен |

## Как запустить
1. Установите Docker Desktop.
2. Скачайте репозиторий и откройте терминал в его корне.
3. Запустите `docker compose up --build -d`.
4. Откройте **http://localhost:8080**.

Проверка: `docker compose ps`; логи: `docker compose logs -f`; остановка: `docker compose down`.

В базе при первом запуске создаются три демонстрационных проекта. Данные сохраняются в Docker volume `postgres_data`. Для настройки пароля скопируйте `.env.example` в `.env` и установите `DB_PASSWORD`. Не публикуйте `.env`.

## Функции для демонстрации преподавателю
1. Покажите четыре запущенных контейнера командой `docker compose ps`.
2. На сайте продемонстрируйте список проектов, добавление проекта, изменение статуса и удаление.
3. Нажмите «Рассчитать» — Backend вызывает отдельный Web-service.
4. Перезапустите контейнеры и покажите, что проекты остались в базе.

## API
- GET /api/projects
- POST /api/projects
- PATCH /api/projects/{project_id}
- DELETE /api/projects/{project_id}
- POST /api/estimate
- GET /api/health
