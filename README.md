## О проекте

**DesignHub** — локальное веб-приложение для организации работы графического дизайнера. Сервис помогает вести список заказов, отслеживать этапы выполнения и рассчитывать предварительную стоимость дизайн-услуг.

Цель работы — разработать веб-приложение из **четырёх взаимодействующих контейнеров**, запустить их с помощью **Docker Compose** и обеспечить сохранение данных в базе.

## Возможности

- **Проекты:** просмотр списка, создание нового проекта, указание клиента, категории и срока выполнения.
- **Статусы:** изменение состояния проекта («В работе», «На проверке», «Завершён»), автоматическое обновление статистики.
- **Управление данными:** сохранение проектов в PostgreSQL и удаление записей.
- **Калькулятор:** расчёт стоимости по категории, количеству услуг и срочности заказа (+25%).

> Обратите внимание: пункты бокового меню «Рабочий процесс» и «Калькулятор» в текущей версии обозначают части интерфейса, но не переключают отдельные страницы. Рабочие функции находятся на основной странице.

## Технологии и архитектура

| Компонент | Технология | Назначение |
|---|---|---|
| **Frontend** | HTML, CSS, JavaScript, Nginx | Веб-интерфейс, формы и кнопки |
| **Backend** | Python, FastAPI | Обработка запросов к данным и калькулятору |
| **Database** | PostgreSQL 16 | Хранение проектов, клиентов и статусов |
| **Web-service** | Python, FastAPI | Независимый сервис расчёта стоимости |

Все компоненты подключены к общей сети Docker Compose:

```text
Браузер → Frontend (Nginx :8080) → Backend (FastAPI)
                                      ├──→ Database (PostgreSQL)
                                      └──→ Web-service (калькулятор)
```

## Запуск приложения

Для запуска требуется установленный и открытый **Docker Desktop**.

1. Скачайте проект через **Code → Download ZIP** и распакуйте архив.
2. Откройте терминал в папке проекта, где находится `docker-compose.yml`.
3. Выполните команду:

```bash
docker compose up --build -d
```

4. После завершения сборки откройте в браузере **http://localhost:8080**.

При первом запуске создаются три демонстрационных проекта.

Чтобы убедиться, что все четыре контейнера запущены, выполните:

```bash
docker compose ps
```

Для остановки приложения:

```bash
docker compose down
```

## Как проверить функции

1. На главной странице посмотрите список проектов и статистику.
2. Нажмите **«+ Новый проект»**, введите название и клиента, выберите категорию и создайте проект. Количество записей увеличится.
3. Измените статус проекта в выпадающем списке и проверьте обновление статистики.
4. Прокрутите страницу до калькулятора, выберите тип услуги и количество, нажмите **«Рассчитать»**. Запрос обрабатывает отдельный Web-service.
5. При необходимости удалите тестовый проект.

**Проверка сохранения:** после создания проекта выполните `docker compose down`, затем `docker compose up -d` и обновите страницу. Данные должны сохраниться благодаря Docker volume `postgres_data`.

## Структура исходного кода

```text
DesignHub/
├── docker-compose.yml      # Конфигурация четырёх контейнеров
├── README.md               # Описание проекта
├── .gitignore              # Исключения для Git
├── .env.example            # Пример настройки переменных
├── frontend/               # Веб-страница, стили и JavaScript
├── backend/                # REST API на FastAPI
├── db/                     # SQL для создания начальных данных
└── web-service/            # Отдельный калькулятор стоимости
```

## Техническая информация: API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/projects` | Список проектов |
| POST | `/api/projects` | Создание проекта |
| PATCH | `/api/projects/{project_id}` | Изменение статуса |
| DELETE | `/api/projects/{project_id}` | Удаление проекта |
| POST | `/api/estimate` | Расчёт стоимости |
| GET | `/api/health` | Проверка Backend |

База данных автоматически инициализируется файлом `db/init.sql`. PostgreSQL использует постоянное хранилище `postgres_data`. Настройки подключения передаются через переменные окружения; образец — `.env.example`. Файл `.env` не следует загружать в репозиторий.
